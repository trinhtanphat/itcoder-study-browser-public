# Independent validation on Windows 11 VM (PVE161) — 15 November 2026

This is supplementary proof that the public, independently authored Windows x64
ITCoder Study Browser runs its offline compiled tests on a **second Windows 11 system**
(not WIN11-181).

The public v0.5.9 GitHub ZIP was downloaded, verified SHA-256 on the Proxmox host,
and transferred to Windows VM 100 via QEMU Guest Agent without opening guest
network ports. Windows `certutil -hashfile` independently confirmed:

`4E300286A230B1B6D0898F4F921643F620EF09F584F81660EEA2C308D17D22AE`

The ZIP was extracted fresh under a scoped QA directory. The standalone release EXE
was executed in safe command-line modes, and the **public**
`scripts/verify-windows-portable-nongui.ps1` was executed in the guest itself.

| Item | Verified |
|---|---|
| ZIP SHA-256 matches GitHub | PASS |
| File manifest SHA-256 and sizes | 486/486 PASS |
| Compiled C# policy checks | 13/13 PASS |
| Executable no-GUI probes | 6/6 PASS |
| WebView2 Runtime available | PASS |
| Service Session 0 GUI guard | PASS (expected exit 40) |
| Real interactive window | NOT TESTED |
| Website account login | NOT TESTED |
| Official vendor exam parity | NOT TESTED |

The guest was not rebooted, its firewall and users were not changed, and no
interactive user session was touched. This does **not** certify the application
for official HUTECH exams. It is an independent HTTPS study browser.

Machine-readable evidence: [VM161-QA-20261115.json](VM161-QA-20261115.json).

QEMU Guest Agent file transfer uses official `guest-file-open`,
`guest-file-write`, `guest-file-flush`, and `guest-file-close` operations.
Consult the [QEMU Guest Agent protocol reference](https://www.qemu.org/docs/master/interop/qemu-ga-ref)
for this portable, non-interactive transfer method.
